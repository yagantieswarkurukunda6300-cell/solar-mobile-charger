<h2 align="center">🌞 POWER YOUR WORLD WITH SUNLIGHT ⚡</h2>

<p align="center">
  An interactive solar-energy simulation that demonstrates the conceptual journey from sunlight to mobile charging.
</p>

## ✨ FEATURES

| ☀️ Solar Energy | ⚡ Live Calculations |
|---|---|
| Adjustable sunlight intensity | Estimated voltage, current and power |
| 🌈 Interactive Visuals | 🔋 Smart Indicators |
| Animated solar-energy scene | Simulated charging status and battery indicator |

- 🎛️ Adjustable sunlight from 0% to 100%
- 🌞 Low, medium and peak sunlight presets
- 🔌 Station ON/OFF controls
- 📱 Solar panel and mobile charging illustration
- 🔄 Reset simulation option
- 📱 Responsive interface for different screen sizes
